# Nodem™ SBC OS

Reference software and engineering baseline for the NOD-SBC-001 Nodem™ Single Board Computer platform.

## Current baseline

- Hardware: NOD-SBC-001, Rev A reference architecture
- Software: NOD-SBC-OS
- Role: reusable compute platform for Nodem™ handheld, Micro-ManPack™, ManPack, vehicle, and fixed-node variants
- Architecture status: interface/architecture freeze; production component selection remains open

## Repository intent

This repository is the software-facing baseline for NOD-SBC-001. Hardware interfaces are treated as stable contracts while processor, FPGA, PMIC, connector, PCB, and thermal component selections can evolve through controlled revisions.

See `docs/NOD-SBC-001-REFERENCE-DESIGN.md` for the reference architecture and freeze boundary.
